# Changelog

## 0.1.0

- Introduced a clean MATLAB package architecture independent of the legacy tree.
- Added validated experiment configuration and named scene catalog.
- Added point-target FMCW simulation, complex range-Doppler processing,
  time-domain and RD-cube near-field imaging.
- Added coherent/non-coherent fusion, radar amplitude equalization, coherence
  factor, explicit oracle angle gating, and dual-frequency multiplication.
- Added localization, target-pair, Top-N, target-coverage, PSLR, and sidelobe
  correlation metrics.
- Added unit, integration, and regression-oriented smoke tests.
