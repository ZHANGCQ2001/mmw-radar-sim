# Array families

Supported radar x-coordinate families over the 1.5-4.5 m aperture:

- three-radar baseline: `[1.5, 3.0, 4.5]`
- five-radar uniform
- five-radar Golomb-like marks `[0, 1, 4, 9, 11]`
- six-radar uniform
- six-radar Golomb-like marks `[0, 1, 4, 10, 12, 17]`

All current radars are on `y=0`, `z=1.2 m`, facing `+y`.
